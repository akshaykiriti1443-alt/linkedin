# SFX Assets

Replace these placeholder files with real sound effects:

| File | Usage | Suggested source |
|------|-------|-----------------|
| `whoosh.mp3` | Transitions, "next", "now", "so" | freesound.org search "whoosh" |
| `click.mp3` | UI actions, "click", "tap", "open" | freesound.org search "click ui" |
| `typing.mp3` | Code, "type", "terminal", "npm" | freesound.org search "keyboard typing" |

Keep files short (0.1–1.0s). They auto-mix at -18dB under your voice.
