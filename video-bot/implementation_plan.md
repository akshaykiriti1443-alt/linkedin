# Implementation Plan — SFX Upgrade (learn from soundeffects-claude-code)

## [NEW] engine/build_sfx_track.py
- pydub-based: load sfx/*.wav, normalize, overlay at millisecond positions
- Reads workspace/sfx_events.json: [{sfx, at_ms}]
- Spacing rules: 1.5s min between any SFX, 7s min between same type
- Outputs workspace/sfx_track.wav (mixed, 48kHz stereo)
- Trims each SFX to max 1s

## [NEW] engine/generate_placeholder_sfx.py
- Pure stdlib (wave + struct + math) — no pip deps
- Generates 12 distinct-sounding WAV placeholders in sfx/
- Different tones/patterns per SFX type so they're identifiable

## [NEW] engine/pyproject.toml
- pydub, ffmpeg-python deps

## [NEW] sfx/ directory with 12 placeholder WAVs
- Generated by running generate_placeholder_sfx.py once
